# ClawDocs

ClawDocs is a Docusaurus-based multi-documentation portal for the Claw product suite.

## Documentation spaces

- `Openclaw`
- `NemoClaw`
- `HiTechClaw`
- `ClawSpark`
- `Docs Khác`

Each documentation space is configured as an independent docs instance with its own sidebar and route.

## Install dependencies

```bash
npm install
```

## Run locally

```bash
npm start
```

## Build production site

```bash
npm run build
```

## Notes

- Homepage links to the `Openclaw` docs by default.
- Add new markdown files inside each product folder to expand that product's documentation.
- Sidebars are autogenerated per documentation space.
